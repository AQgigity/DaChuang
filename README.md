# 基于分布式双 ESP32-S3 架构的多模态运动生物力学监测系统

本项目是一款全栈式、分布式的智能化人体运动状态检测与生物力学分析系统。项目入选**桂林电子科技大学大学生创新训练计划项目（国家级）**，并已形成相关的发明专利交底方案与学术论文。

系统突破了传统单节点穿戴设备（如单一智能手表或跑鞋）数据维度单一、缺乏跨肢体协同分析的局限，创新性地构建了 **“脚踝传感终端（感知与边缘推理） - 手表处理终端（人机交互与特征融合） - 物联网云端/App（数据生态闭环）”** 的分布式双主控网络。

---

## 🚀 项目核心亮点 (Core Highlights)

* **分布式双 ESP32-S3 主控架构**：系统将高频传感器并发采集、轻量化神经网络推理、LVGL 图形渲染及网络上报等高负载任务，合理解耦并分布在两台 ESP32-S3 芯片上，有效解决了传统单主控穿戴设备在多路信号并发处理时的实时响应瓶颈。
* **多模态生物力学感知矩阵**：
  * **下肢（脚踝端）**：集成 MPU6050 六轴惯性传感器与双路 FSR402 足压传感器，精准捕捉步态动力学特征。
  * **上肢（手表端）**：集成 EMG 肌电传感器（摆臂频率监测）、BMP280 气压温度计及 MAX30102 心率血氧传感器，实现“上肢摆臂-下肢步态-生理指标-环境参数”的全维度交叉融合。
* **低延迟 BLE 穿戴协议优化**：针对多模态高频数据流传输场景，优化了低功耗蓝牙（BLE）的通信报文结构，采用 **Notify 异步通知模式** 实现了脚踝端至手表端的高速数据同步。
* **边缘智能计算 (Edge AI)**：基于 **Edge Impulse** 平台训练并部署轻量化神经网络分类模型，在边缘侧直接进行毫秒级动作识别（静止、跑步、跳跃等），大幅降低系统对云端算力和网络连接的强依赖。
* **高鲁棒性步态序列算法**：设计了基于时间戳触发的足底发力状态二值化序列匹配算法，配合动态阈值窗口与防抖死区锁定机制，能够精准识别复杂运动中的发力逻辑（前脚掌、后脚跟、全脚掌发力等），对传感器噪声和个体差异具备极强的抗干扰能力。

## 🛠 技术栈与工程框架 (Tech Stack)

* **核心硬件**：ESP32-S3 (Xtensa® 双核 32 位 LX7 处理器)
* **嵌入式开发框架**：ESP-IDF / FreeRTOS 多任务协同调度
* **人机交互 GUI**：LVGL (Light and Versatile Graphics Library) 图形渲染引擎
* **信号处理与算法**：ADC 多通道采样、数字滤波去噪、肌电信号特征提取、足压时序差异算法
* **边缘 AI 部署**：Edge Impulse 嵌入式深度学习推理
* **物联网协议与云端**：MQTT 协议、OneNET 物联网云平台、定制化手机 App

## 🏗 系统架构与逻辑演进 (System Architecture)

### 1. 脚踝传感终端 (感知与推理节点)
* **多通道并行采集**：通过 I2C 总线以高采样率读取 MPU6050 的加速度与角速度，同时利用内置 ADC 实时量化双路 FSR402 压力变化。
* **发力瞬态二值化编码**：实时监测 FSR 输出电压 $V_{FSR}$，当信号触发设定阈值时精确记录时间戳，并将电压信号转换为二值化状态（1:超过阈值，0:低于阈值），实时构建包含前后脚掌组合的二进制序列（`00`：未发力，`10`：前脚掌发力，`01`：后脚跟发力，`11`：全脚掌发力）。
* **边缘推理与封包**：将清洗后的惯性及压力特征输入本地神经网络，分类出当前的运动状态标签，并联同发力模式、实时步频封装为标准化通信包，通过 BLE 发送。

### 2. 手表处理终端 (融合与交互节点)
* **数据解析与多源融合**：BLE 中央设备解包接收脚踝侧数据，并同步结合本地 EMG 肌电传感器的摆臂频率、心率血氧及 BMP280 环境指标进行重构映射。
* **LVGL 本地仪表盘渲染**：基于 LVGL 深度定制运动交互界面，将融合后的多维生物力学参数通过平滑的动效和直观的视觉仪表盘呈现。
* **多终端生态联动**：内部任务通过 MQTT 客户端，以 2 秒/次的频率将完整的结构化数据集同步至 OneNET 物联网平台，供配套手机 App 订阅，实现长周期运动健康趋势看板展示。

## 💡 经验教训与开发建议 (Developer Guide)

根据大创项目实际调试经验，后续开发者在进行该系统二次开发或优化时，建议注意以下几点：
1. **PCB 抗干扰布局**：肌电（EMG）信号极其微弱，在设计手表端硬件时，务必注意模拟地（AGND）与数字地（DGND）的单点接地隔离，提前做好噪声分析，避免 ESP32-S3 射频通信对模拟前端造成高频纹波干扰。
2. **边缘 AI 数据集多样性**：当前预装的动作分类模型在单人数据集下表现良好。若要进行商业化或更深度的科学研究，建议扩展多样本、多人群的运动数据集进行联合训练，以提升神经网络模型在边缘端的鲁棒性与泛化能力。
3. **通信死区（Dead-Zone）校准**：步频提取算法依赖足底压力的触地瞬态事件，在不同体重或不同材质的运动鞋垫下，需动态调整阈值触发窗口与防抖锁定时间，以防止多重触发带来的误判。
